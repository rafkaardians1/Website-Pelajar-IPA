Pengenalan HTML dan CSS

Apa Itu HTML?

HTML atau bisa disebut HyperText Markup Language adalah bahasa markah standart untuk membuat struktur, kerangka atau pondasi dari halaman website. HTML memilki beberapa tag dan elemen yang membantu mengatur tata letak teks, gambar dan konten website lainnya. HTML adalah bahasa penadaan (markup) bukan sejenis bahasa logika (bahasa yang menggunakan operator logika) seperti Javascript, Phython, C++ dan lainnya.

Apa Itu CSS?

CSS atau Cascading Style sheet adalah bahasa yang digunakan untuk mengatur tampilan, tata letak, format dan format pada website. Fungsi utamanya adalah untuk memberikan gaya atau hiasan pada struktur HTML sehingga dapat digunakan untuk adanya pengubahan font, warna dan lain sebagainya.

Hubungan antara HTML dan CSS ini sangat penting. HTML diibaratkan sebagai pondasi untuk membuat rumah sedangkan CSS diibaratkan sebagai isi dari HTML mulai dari warna dinding, tata letak dan lain sebagainya.
